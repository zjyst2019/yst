# eVS Wiki Chat Server - Requirements

## 系统要求

1. Node.js >= 18.0.0 (推荐 v20+ 或 v24+)
   - 用于运行服务器和安装 npm 包
   - 下载: https://nodejs.org/

2. Claude CLI (@anthropic-ai/claude-code)
   - 用于调用 Claude API 并读取本地知识库文档
   - 安装: npm install -g @anthropic-ai/claude-code
   - API 配置通过 settings.json 文件配置（推荐）

## Claude CLI 配置

### 方式一：通过 settings.json 配置（推荐）

配置文件位置：
- Windows: %USERPROFILE%\.claude\settings.json
- Linux/macOS: ~/.claude/settings.json

配置示例：
```json
{
  "apiKey": "your-api-key",
  "baseUrl": "http://192.168.1.100:8080",
  "model": "MiniMax-M2.7"
}
```

查看当前配置：
```bash
claude config
```

### 方式二：通过环境变量配置（可选）

环境变量优先级高于 settings.json，可用于临时覆盖：

```bash
# Windows
set ANTHROPIC_API_KEY=your_api_key
set ANTHROPIC_BASE_URL=http://192.168.1.100:8080
set CLAUDE_MODEL=MiniMax-M2.7
```

## Node.js Dependencies (通过 npm install 自动安装)

运行 `npm install` 将自动安装以下依赖:

- express@^4.18.2        - Web 服务器框架
- ws@^8.16.0             - WebSocket 实现
- better-sqlite3@^12.9.0 - SQLite 数据库绑定
- uuid@^9.0.1            - UUID 生成工具
- marked@^12.0.0         - Markdown 解析器 (前端使用 CDN 版本)
- @anthropic-ai/sdk      - Anthropic API SDK (可选模式)

## 快速安装步骤

# 1. 安装 Node.js
# Windows: 从 https://nodejs.org/ 下载安装包

# 2. 安装 Claude CLI
npm install -g @anthropic-ai/claude-code

# 3. 配置 Claude CLI settings.json（推荐）
# 编辑 %USERPROFILE%\.claude\settings.json
# 填入 apiKey, baseUrl, model

# 4. 进入项目目录
cd claude_web_server

# 5. 安装项目依赖
npm install

# 6. 配置知识库路径 (Windows)
set CLAUDE_WORK_DIR=D:\knowledge-base
set SYSTEM_PROMPT_FILE=D:\knowledge-base\CLAUDE.md

# 7. 启动服务器
npm start

# 8. 打开浏览器访问
http://localhost:3000

## 环境变量配置表

### 必须配置（CLI 模式）

| 变量 | 说明 |
|------|------|
| CLAUDE_WORK_DIR | 知识库目录 |
| SYSTEM_PROMPT_FILE | CLAUDE.md 文件路径 |

### 可选配置（优先级高于 settings.json）

| 变量 | 说明 |
|------|------|
| PORT | 服务器端口（默认 3000） |
| ANTHROPIC_API_KEY | API Key |
| ANTHROPIC_BASE_URL | API 网关地址 |
| CLAUDE_MODEL | 模型名称 |
| MAX_HISTORY_MESSAGES | 最大历史消息数（默认 5） |
| USE_SDK | 设置为 true 使用 SDK 模式 |

## 知识库配置

1. 知识库目录结构
   ```
   D:\knowledge-base\
   ├── CLAUDE.md           # 知识库说明（系统提示）
   ├── wiki/
   │   ├── index.md        # 知识目录
   │   ├── guide/          # 使用指南
   │   └── api/            # API 文档
   └── docs/
       └── ...
   ```

2. CLAUDE.md 内容示例
   ```markdown
   # 项目知识库

   ## 文档结构
   - wiki/index.md - 知识目录，包含所有文档索引
   - wiki/guide/ - 使用指南
   - wiki/api/ - API 文档

   ## 查询建议
   用户提问时，先查阅 wiki/index.md 了解文档位置，
   然后根据问题内容读取相关文档进行回答。
   ```

3. 配置示例
   ```bash
   # Windows
   set CLAUDE_WORK_DIR=D:\knowledge-base
   set SYSTEM_PROMPT_FILE=D:\knowledge-base\CLAUDE.md
   npm start
   ```

## 数据库

- SQLite 数据库文件将自动创建在 data/chat.db
- 无需额外安装数据库服务
- 存储用户会话和聊天历史

## CLI vs SDK 模式

| 模式 | API 配置方式 | 知识库支持 |
|------|-------------|-----------|
| CLI (默认) | settings.json 或环境变量 | 支持 |
| SDK | 必须环境变量 | 不支持 |

## 验证 Claude CLI 配置

```bash
# 测试 CLI 是否正常工作
claude -p "hello"

# 查看配置
claude config
```
