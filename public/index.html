使用说明

                
            

            

                

                    
📁 文件浏览器

                    
    
                        
  • 浏览文件 — 点击文件夹进入，点击文件查看内容
    • 
                        
  • 上传文件 — 选择文件后点击"上传文件"，上传到当前目录
    • 
                        
  • 新建文件夹 — 点击"+ 新建文件夹"输入名称创建
    • 
                        
  • 删除文件 — 鼠标悬停文件，点击右侧 × 按钮（确认后删除）
    • 
                        
  • 摄入知识库 — 上传文件到 upload/ 目录后，点击"📥 摄入知识库"，勾选文件确认摄入
    • 
                        
  • 附加提示词 — 摄入时可填写，指导模型处理重点（如"重点关注性能配置"）
    • 
                    

                

                

                    
💬 问答结果确认

                    
    
                        
  • 满意 ✓ — 回答满意时点击，将问答存入缓存，后续相似问题直接返回缓存答案
    • 
                        
  • 补充知识 — 回答不满意时点击，按模板格式输入：
                            
    需要补充的知识：<知识内容>
                            
    摄入知识的要求：<对提取/整理的要求，可选>
                            
    未按模板输入时，AI 会自动分析分离知识内容与指令 → 写入知识库
    • 
                        
  • 自动关联 — 系统检测到新回答与缓存答案相似度 ≥ 95%，自动链接问题
    • 
                        
  • 合并确认 — 相似度 90%-95% 时提示用户确认，合并为新答案写入缓存
    • 
                        
  • (缓存) — 该回答直接来自缓存，无需调用 API
    • 
                    

                

                

                    
⌨ 其他操作

                    
    
                        
  • Stop — 停止正在生成的回答
    • 
                        
  • 清空对话 — 开始新的对话（不保留历史上下文）
    • 
                        
  • Enter 发送 — 直接按 Enter 键发送消息
    •
